# 联网调研

两个工具，两种用法。`web_search` 负责「有哪些页面」，`web_fetch` 负责「这一页到底写了什么」。
搜完不读、读前不搜，都是把猜测当成事实。

## 一、先搜，再读

`web_search`

- `query`（必填）：用人会说的话，不要堆关键词。
- `limit`：默认 10，最多 50。一次要 10 条够判断方向了，不够再加。
- `language`：`zh-CN` 或 `en`。中文问题和英文问题要各搜一次——同一件事两边的资料不是同一批。
- `categories`：`general` 默认；查新近事件用 `news`，查库与工具用 `it`。

返回的每条有标题、URL、摘要。摘要只用来挑页面，不能当结论引用——摘要经常是页面里的
无关首段，甚至是搜索结果页自己的推荐语。

`web_fetch`

- `url`（必填）：绝对 http/https 地址，必须是公网地址（集群内网、回环地址会被拒，拒绝时会说明原因）。
- `max_chars`：默认 20000，最多 200000。够读一篇文档的正文；超长页面先小后大，别一上来就要 20 万字符。

返回页面标题与正文文本。HTML 会被压成正文，纯文本与 JSON 原样返回；二进制文件只报类型不返回内容。

## 二、查询怎么排

同一件事值得写三条不同的查询，而不是把一条查询换十个词：

1. 原始问题本身（用提问者的话）。
2. 加上限定词：`site:docs.rs`、`site:github.com`、`site:developer.mozilla.org`，
   或时间词 `2026`、`latest`、`release notes`、`changelog`。
3. 换成报错的原文片段（带引号会提高精确匹配的概率），或换成另一种语言。

查版本号、API 签名、命令行参数这类**会变的事实**，以官方文档与仓库的 release 页为准；
博客与问答只用来找线索，不用来定版本。

## 三、搜不到东西时的直达模板

`web_search` 返回空、或只返回噪音时，说明元搜索这一路没打通，不要就此下「网上没有」的结论。
改用 `web_fetch` 直接请求搜索页，再把结果页里的链接挑出来逐条读：

| 引擎 | 查询地址模板 | 说明 |
| --- | --- | --- |
| 必应（中国） | `https://cn.bing.com/search?q={查询}&setlang=zh-CN` | 最稳，中英文都收 |
| 360 搜索 | `https://www.so.com/s?q={查询}` | 中文长尾较好 |
| 百度 | `https://www.baidu.com/s?wd={查询}` | 结果页依赖脚本，正文常抓不全，只当备用 |
| 搜狗 | `https://www.sogou.com/web?query={查询}` | 微信公号内容较多 |
| 知乎 | `https://www.zhihu.com/search?type=content&q={查询}` | 需要脚本，多数情况抓不到正文 |
| GitHub 代码 | `https://github.com/search?q={查询}&type=code` | 未登录会拦，改成查仓库页或 README |
| 掘金 | `https://juejin.cn/search?query={查询}` | 中文工程实践 |

`{查询}` 要按 URL 编码（空格变 `%20`，中文直接用 UTF-8 百分号编码）。
抓回来的若是「请开启 JavaScript」「验证你不是机器人」，就换下一个引擎，不要反复试同一个。

已知在本集群网络里**不通**的源：google、duckduckgo、brave、wikipedia、r.jina.ai。
列在这里是为了省一次超时，不是为了绕。

## 四、读一页的规矩

1. 摘到正文再引用。只拿到标题和摘要时，最多说「有这样一个页面」，不说它写了什么。
2. 页面里没有你要的那句，就换页面。同一站点连抓三页都没有，基本可以判断这个站点没有。
3. 一个事实两个来源不一致，以更接近源头的一方为准（官方文档 / 原始仓库 / 发布说明优先于
   转载博客 / 聚合站 / AI 摘要页），并把分歧写出来，不要二选一蒙过去。
4. 页面上标注的时间要看。三年前的答案对「当前版本」几乎总是错的。

## 五、引用与止损

每一条来自网络的结论都带上：页面标题、URL、以及你是今天读到的。三者缺一，读者无从复核。

止损（不是为了省钱，是为了不把一个查不出的事拖成十轮）：

- 一个问题两轮查询、六次抓取之内必须给出结论或明确说「查不到」。
- 同一个 URL 本任务内只抓一次；重复抓取说明查询在打转。
- 连续两个源返回 4xx/5xx/空正文，停下来说明情况，不要继续撞。

## 六、不做的事

- 不访问需要登录、付费、或「同意后才能看」的内容，也不尝试绕过这类限制。
- 不伪造 URL、不把记忆里的地址当成刚读到的内容。
- 不把搜索结果的摘要拼接成一篇「调研报告」——那是没读。
- 不上传、不提交任何凭据或内网地址到外部站点。
